### FASE 2 — docker-compose.yml - OK

O trabalho exige:
- Rede Docker própria com sub-rede definida
- IP fixo para cada container
- Pelo menos um container cliente para testes

| Container | IP |
|---|---|
| gateway (bridge do Docker) | `172.30.10.1` |
| mailpit | `172.30.10.2` |
| cliente_email | `172.30.10.3` |

(conteúdo completo no arquivo `docker-compose.yml`)

---

### FASE 3 — Subir e testar - OK

```bash
docker compose up -d
```

**Testar envio via SMTP pelo terminal (dentro do container cliente):**
```bash
docker exec -it cliente_email sh
apk add --no-cache netcat-openbsd

nc -C mailpit 1025
```

> `-C` faz o nc enviar `\r\n` (CRLF) no fim de cada linha, que é o que o SMTP exige.
> Assim não precisa do truque do `ctrl+v` + enter (`^M`) para o ponto final.

Depois digitar manualmente os comandos SMTP (isso é o que a professora quer ver na captura):
```
EHLO cliente.local
MAIL FROM:<usuario1@teste.com>
RCPT TO:<usuario2@teste.com>
DATA
Subject: Teste SMTP
From: <usuario1@teste.com>
To: <usuario2@teste.com>

Olá! Mensagem de teste.
.
QUIT
```

**Ver o e-mail recebido:** acesse `http://localhost:8025` no navegador.

---

### FASE 4 — Captura de tráfego com tcpdump

A ordem importa: a captura precisa estar rodando ANTES do envio. Use dois terminais.

**Terminal 1 — iniciar a captura (dentro do mailpit):**
```bash
docker exec -it mailpit sh
apk add --no-cache tcpdump
tcpdump -i eth0 -U -w /tmp/captura.pcap port 1025
```
> `-U` grava cada pacote no arquivo na hora (sem buffer).

**Terminal 2 — enviar o e-mail:** repetir a FASE 3 (`nc -C mailpit 1025` ...).

**Terminal 1 — parar a captura:** `Ctrl+C` (só depois disso o .pcap fica completo).

Depois copie o arquivo para o host para analisar no Wireshark:
```bash
docker cp mailpit:/tmp/captura.pcap ./captura.pcap
```

---

### FASE 5 — O que mostrar no Wireshark

ATENÇÃO: o Wireshark só reconhece SMTP na porta 25. Na porta 1025 ele mostra
apenas TCP. Para decodificar:

1. Clique com o botão direito num pacote → **Decode As...**
2. Campo `TCP port` = `1025` → Current = **SMTP** → OK
3. Filtro de exibição: `smtp`
4. Opcional: botão direito → **Follow → TCP Stream** mostra a conversa inteira

A professora exige mostrar:
- Comando `EHLO`
- `MAIL FROM`
- `RCPT TO`
- `DATA`
- Códigos de resposta:
  - `220` — servidor pronto (saudação inicial)
  - `250` — comando aceito (EHLO, MAIL FROM, RCPT TO, fim do DATA)
  - `354` — pode enviar o corpo, termine com `.`
  - `221` — encerrando a conexão (resposta ao QUIT)
